# ML & AI — учебные проекты

Коллекция учебных работ, экспериментов и решений задач по машинному обучению на Python. Основная часть материалов оформлена как Jupyter-ноутбуки: в них собраны подготовка данных, обучение моделей, оценка результатов и визуализации.

> Репозиторий является портфолио учебных проектов, а не единым готовым Python-пакетом. У каждой работы могут быть свои зависимости, датасеты и требования к вычислительным ресурсам.

## Выделенные работы

### Reinforcement Learning

- **Atari Carnival** — Double Deep Q-Network (DDQN) со свёрточной сетью, replay buffer и Double Q-Learning loss. Основной ноутбук: [`RL/1/atari_carnival_ddqn(1).ipynb`](<RL/1/atari_carnival_ddqn(1).ipynb>).
- **Maze RL** — генерация идеальных лабиринтов алгоритмом Краскала и обучение CNN Actor–Critic методом PPO. Обучение строится в три этапа: исследование, поиск выхода и прохождение кратчайшим путём. Основной вариант: [`RL/3/2/maze_rl_8.ipynb`](RL/3/2/maze_rl_8.ipynb).

### NLP

- Классификация последовательностей и Seq2Seq-модели на RNN.
- Transfer learning для классификации текстов.
- Text retrieval: поиск ответов на вопросы по корпусу данных.
- Retrieval-augmented generation (RAG).

### Computer Vision и нейросети

- Классификация рукописных японских символов **Kuzushiji-49**.
- Эксперименты с **CIFAR-10**, **Tiny ImageNet** и **Caltech-101**.
- Детекция, работа с ключевыми точками и обработка изображений.

## Быстрый старт

### 1. Клонируйте репозиторий

```powershell
git clone https://github.com/MaximSave/ML-iibd.git
cd ML-iibd
```

### 2. Подготовьте окружение

Рекомендуется Python 3.10+ и отдельное виртуальное окружение.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install jupyterlab numpy pandas matplotlib seaborn scikit-learn
```

Для конкретных ноутбуков могут дополнительно потребоваться `tensorflow`, `torch`, `gymnasium`, `opencv-python`, `Pillow`, `tqdm` и другие библиотеки. Устанавливайте их по импортам в выбранном ноутбуке:

```powershell
python -m pip install tensorflow gymnasium opencv-python pillow tqdm
```

### 3. Откройте ноутбук

```powershell
jupyter lab
```

В браузере перейдите к нужному разделу и запускайте ячейки последовательно. Некоторые проекты загружают внешние датасеты или требуют GPU — это указано в самих ноутбуках.

## Важные замечания

- Ноутбуки с суффиксами `v2`, `v3` и т. п. — последовательные версии экспериментов; обычно стоит начинать с наиболее поздней версии.
- Файлы данных и результаты обучения могут быть большими. Перед запуском проверьте доступное место на диске и при необходимости настройте пути к данным в ноутбуке.
- Для задач с обучением нейросетей GPU заметно сократит время экспериментов, но не обязателен для просмотра кода и небольших запусков.
